Network Health Monitoring System

Project Overview

The Network Health Monitoring System monitors network device connectivity and displays the results on a web dashboard. It identifies devices that are down and highlights network performance issues.

Technologies Used

- Python
- Flask
- HTML and CSS
- Docker
- Jenkins
- Kubernetes (Minikube)

How to Run the Project

1. Install Python.

2. Open the project folder in VS Code.

3. Open the terminal and install the required packages:
   
   "pip install -r requirements.txt"

4. Run the application:
   
   "py app.py"

5. Open "http://127.0.0.1:5000" in your browser.

Project Features

- Network connectivity monitoring
- Latency and packet-loss monitoring
- Network health status and alerts
- Web-based dashboard
- Docker containerization and CI/CD pipeline

Kubernetes

The application can also be deployed using the Kubernetes configuration files in the "k8s" folder.
